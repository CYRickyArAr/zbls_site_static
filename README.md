# ZBLS 公式库

<p align="center">
  <strong>简体中文</strong> | <a href="README.en.md">English</a>
</p>

一个收录 **305 个 ZBLS 情况**的在线公式库，包含情况图、多套公式与选手实战使用标注。

ZBLS（Zborowski-Bruchem Last Slot）是一套在完成最后一组 F2L 的同时，定向顶层棱块的公式体系。本站采用 [SpeedCubingTips.eu](https://www.speedcubingtips.eu/zbls-zborowski-bruchem-last-slot/) 的 42 类分类方式，收录 305 个情况，并标注耿暄一、连允之等选手实际使用过的公式。已排除完成复原的 C37-4，其余情况保留来源编号。

基础分类及来源公式取自 [SpeedCubingTips.eu](https://www.speedcubingtips.eu/zbls-zborowski-bruchem-last-slot/)，选手实战使用标注根据复盘记录整理，包括 [reco.nz](https://reco.nz/) 的复盘。**选手标注只表示曾在实战中使用，不代表当前主力公式；没有选手标注的来源公式不代表任何选手的使用记录。**

内容仅供学习与参考，本站将持续更新。**如发现公式错误或其他问题，欢迎反馈指正。**

## 内容

- **305 个 ZBLS 情况**：每个情况均提供状态图及对应公式，部分情况收录多套公式。分类图与具体情况图均随深浅色主题切换。
- **42 个分类**：C1–C36 各 8 个情况；C37 为 3 个，C38 / C41 / C42 各 2 个，C39 / C40 各 4 个。
- **选手实战标注**：标注每条公式实际使用过的选手；多人使用同一公式时合并显示（如「耿 连」）。
- **默认大神版**：可直接预览整理后的公式与选手标注。
- **个人公式库**：在同一个库中选择显示哪些大神公式、添加自己的公式，并通过 `.zbls` 文件备份或迁移。

## 使用

### 浏览与选择公式库

点击顶部「文 / A」语言图标可切换「简体中文 / English」。首次访问跟随浏览器语言，手动选择后会记住。英文模式会转换已知选手的展示简称（如耿 → Xuanyi、连 → Yunzhi）；个人库名、备注和标记编辑框里的原文保持不变。

打开网站即可浏览。进入分类后，通过顶部可滚动的分类栏切换 C1–C42，也可按「全部 / 已学 / 未学」筛选；点击左上角网站标志返回首页。点击主题图标可切换深浅色模式。

点击顶部问号可打开「关于本站」，右下角显示网站最近发布的时间（UTC+8），包含公式、界面及功能更新，不受个人库编辑或访问时间影响。

右上角按钮显示当前公式库名称，点击可打开公式库管理：

- **默认大神版**：仅供预览，无需创建公式库即可浏览。首次修改时，会提示创建自己的公式库。
- **个人公式库**：点击新建按钮创建，初始显示全部大神公式。每个库都可选择大神公式、添加自己的公式，并保存图片、备注和学习状态；不同库的内容与设置互不影响。
- **管理公式库**：点击库名切换；个人库右侧菜单可重命名、导出或删除。

网站发布新的大神公式后，刷新页面会自动同步到所有个人公式库；导入旧 `.zbls` 文件时也会同步。已有公式的显示／隐藏选择保留，新增大神公式默认显示。选手标注更新不会重置对应公式的显示选择；个人公式、备注、图片、已学状态和拖动顺序保持不变。已移除的完成复原情况 C37-4 不会因导入旧文件而恢复。

### 编辑与学习

公式开头的前置转体（y、y′、y2）以小标记单独显示；U、U′、U2 仍作为公式的一部分显示，不使用 pre-AUF 标记。这只影响浏览时的样式，不改变公式原文。

在个人公式库中，点击情况卡片上的「编辑」：

- **大神公式**：逐条勾选显示或隐藏，也可对当前情况「全选 / 全不选」。原公式及选手标注不可修改，隐藏不会删除原公式。
- **我的公式**：点击「＋ 添加」，左侧输入公式，右侧填写标记（可选，多个标记用空格分隔）。公式可随时修改；右侧「删除」会删除整条个人公式及其标记。
- **图片与备注**：可更换、清除或恢复图片，填写备注。备注可输入多行，浏览时以单行省略显示。
- **保存 / 取消**：编辑完成后点击「保存」；点击「取消」放弃本次修改。

点击卡片右下角圆形勾选按钮可标记或取消已学，拖动卡片右上角手柄可调整情况顺序，编号保持不变（例如 C31-2 始终为 C31-2）。每个情况还可点击选中一条公式并持续高亮，再次点击取消；选中不会改变公式顺序。

网站个人库的学习进度独立保存在当前浏览器，不与本地数据库的学习进度同步。

### 备份与迁移

编辑后先点击「保存」，再从个人公式库菜单中导出 `.zbls`。文件包含自己的公式与标记、各情况的大神公式显示／隐藏设置，以及图片、备注、学习状态、排序和公式选中状态。

在其他浏览器或设备上打开公式库管理，点击「导入 .zbls」即可恢复为一个独立的个人公式库。

**个人公式库保存在当前浏览器中，不会自动跨设备同步。清理浏览器数据可能导致丢失，请定期导出备份。**
